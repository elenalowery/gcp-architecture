GCP offers three options for building agentic AI applications. They sit at different layers and are not alternatives to each other — a production system often uses all three together: ADK for agent logic, Agent Platform SDK to deploy it, and CX Agent Studio for non-developer builders.

These are not mutually exclusive choices. ADK is the framework, Agent Platform SDK is the deployment layer, and CX Agent Studio is a managed product built on top of ADK for conversational use cases.
