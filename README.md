# GCP Architecture Patterns

A reference collection of Google Cloud Platform architecture patterns for Generative AI, RAG, Agentic Applications, Analytics, and Machine Learning.

## Patterns

| # | Pattern | Description |
|---|---------|-------------|
| 01 | [LLM Inferencing](gcp_patterns/gen_ai/gen_ai_llm_inferencing.html) | Direct, client-gateway, and GCP-gateway inference topologies |
| 02 | [RAG Pattern](gcp_patterns/gen_ai/rag_pattern.html) | Retrieval-augmented generation with GCP vector databases |
| 03 | [Agentic Applications](gcp_patterns/gen_ai/agentic_applications.html) | ADK, Agent Platform SDK, and CX Agent Studio |
| 04 | [Analytics & Data Warehouse](gcp_patterns/gen_ai/analytics_warehouse.html) | Batch and streaming ingestion into BigQuery |
| 05 | [ML Patterns](gcp_patterns/gen_ai/ml_patterns.html) | End-to-end ML workflows on Vertex AI |
